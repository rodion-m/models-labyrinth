# Coding and agentic benchmark research

Snapshot researched 2026-08-26 from the target repository’s current `models_db.json`.

## Scope and method

The JSON contains **122 unique target IDs**: **49 `coding.*`** and **73 `agentic.*`**. This table deliberately retains one row per snapshot ID. Canonical research was deduplicated conceptually, while provider snapshots, aliases, subset lanes, aggregate indexes, and derived fields are labeled in the **Row kind** column.

Primary sources were preferred in this order: official benchmark site or repository, benchmark paper, then an official evaluator/methodology or provider release note. “Unknown” means I could not verify the fact from a primary source; it is not an estimate. Dates are benchmark release/update dates when verifiable, not the date a result happened to be recorded in `models_db.json`.

The target IDs are result-ledger identifiers, not necessarily benchmark names. In particular, AA/provider rows can be display-only composites or vendor snapshots. Their numeric values should not be interpreted as independent benchmark measurements without the underlying task release, evaluator, scaffold, and metric being pinned.
